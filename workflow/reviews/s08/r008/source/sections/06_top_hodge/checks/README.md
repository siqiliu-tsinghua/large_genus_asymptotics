# Supplementary top-Hodge coefficients

This small bundle reconstructs the two reported coefficients in
rmk:s06:further-coefficients. The paper omits their details at the
user's request. This computation does not alter the precision or
proof of Theorem 1.3 and is not a mathematical-review signature.

Run from the repository root with Python 3.10 or newer:

    python -B sections/06_top_hodge/checks/run.py

The pinned dependencies are SymPy 1.14.0 and mpmath 1.3.0. The
program locates the existing workspace-local installation at
build/a-calculations/python-packages and checks both versions.
If that installation is absent:

    python -m pip install --target build/a-calculations/python-packages sympy==1.14.0 mpmath==1.3.0

Only installed package code is loaded from build. No preparation
algorithm, generated coefficient, private result, reference cache,
Appendix A program or Section 4 program is imported. Bytecode is
disabled. Generated output goes only to
build/s06-higher-check/results.json and console text.

## Reconstruction

The algorithm adapts the original writer's independently completed
research calculation into a self-contained source file.

1. The ODE x w''+w=0 and the critical initial values generate the
   circle phase. A finite exponential recursion and exact Gaussian
   moments produce the Phi-power amplitude coefficients through
   inverse cubic order. The phase is computed through degree nine,
   and all odd half-order averages through the seventh vanish.
2. Rooted labeled trees with at most three edges are generated by
   Pruefer sequences. The distinguished vertex has large genus;
   the root's internal marker is not a negative genus. Every small
   genus assignment in the relevant range is tested for stability
   and loss E+sum_small(2g_v-3+n_v)<=3. Small genus at least three
   already has loss at least five and cannot enter these orders.
3. Permutations fixing the large vertex deduplicate the classes
   and compute their automorphism orders. The enumeration produces
   seven types; that count is checked after reconstruction.
4. The sine series supplies the low beta coefficients. Finite
   Phi/J0 extraction gives the actual small-vertex polynomials.
   Internal edge parameters are integrated exactly. The remaining
   Bessel moments satisfy I_0=Phi(X),
   I_j=Phi(X)-j^2 I_(j-1)/X at the critical zero.
5. The factorial and square-root shifts of the large vertex are
   retained when composing all seven groups. The proposed compact
   coefficients enter only the final exact post-comparisons.

The comparison scale is the accepted top-vertex saddle scale
beta_g*g_2!*R^(-g_2)/(J_1(z_{0,1})*sqrt(2pi*g_2)).
Fixed beta genus shifts use the proved exponential asymptotics;
their errors contribute no inverse-power coefficient. Recovering
b_g supplies the second factorial and the factor 12^(-g_2), as
in the original proof. No WP coefficient enters this calculation.

Internal X=x_*, L=pi^2 J_1(z_{0,1})^2/6 and z=1/g_2 are algebra
variables in the code, not manuscript notation. The printed
Remark uses only the already established b and z_{0,1}.
Numerical evaluations are produced after the exact reconstruction
and are not fitting data or coefficient inputs.

## Evidence and limits

The generated JSON records every tree class, its automorphism
order, small-edge amplitude where needed, phase and Gaussian
coefficients, complete grouped coefficients, exact comparison
differences, dependency versions and the actual algorithm SHA256.
The tracked verification.json records the completed execution,
source and output fingerprints, exact reported formulas and
numerical evaluations. Its status is computation_only.

The original writer's research was separately cross-checked by
the coordinator's inverse-function/Puiseux calculation and by the
original mathematical reviewer's research preparation. Those are
provenance of the calculation, not acceptance of this new frozen
Remark. The archived program imports none of those outputs and
does not assert a uniform higher-order remainder. The complete
tree/genus tail and higher saddle proof can be continued by the
same method, but the paper deliberately omits that derivation.
No additional external source or data entry is required here.
